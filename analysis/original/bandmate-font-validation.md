# Bandmate, actor and font reconstruction

This pass implements the four source bandmate action categories in DlgRehearsal01Artist: ten visible gifts, five training/holiday options, praise/slander, and firing. Clicking a hired member opens the artist window over the band window and plays that actor's original status speech. Gift choices preserve native category order and recipient preferences; one-time physical gifts disappear after delivery. Alcohol remains repeatable and its delayed effect applies on exit to the city. Training uses calendar dates, prevents musician/gig conflicts, charges once, completes once, and creates fading source stat modifiers. A musician away on training cannot enter a studio session. Training completion uses original English event-card text.

Source evidence: bandmate-rules-evidence.json and localization-evidence.json. Dynamic mood, health, musicality and charisma are saved and used by recordings and concerts. Relationship changes affect the other band members' attitudes; firing removes the artist and influences friends. Existing saves initialize these fields without changing band, money, album or contract.

Original speech and lip cues are retained in feedback-audio-evidence.json and actor-animation-evidence.json: 1,853 audio files, 17 actor atlases, 1,160 speech cue sequences. Lip frames follow original12Hz cues using actual Web Audio playback position; no audio-amplitude or synthesized speech substitute. Actor layers align using source registration points. The earlier exterior-only white matte was incorrect and left opaque white islands. Native FaceAnim score records use ink36: animation backgrounds and face layers now key every exact-white pixel, including enclosed regions. Nonwhite highlights retain their original color. See actor-score-ink-evidence.json and animation-white-artifacts.md. Idle portraits currently use pose1; the complete original body-transition/blink state machine is not reproduced.

NativeText composes Windows GDI glyph atlases while keeping the Phaser Text interface. XMED style records establish font families, effective sizes, bold flags and tracking. Modern pair kerning is disabled because it disagrees with native body samples. The rendered venue screen matches original foreground masks exactly for Info, Description and its first description line. Reproducible retained checks also match original media category heading/body. Original titlebars use effective Courier New14bold antialiasing; HUD uses Verdana10bold antialiasing. Current GDI antialiasing still differs from Director's cached title/HUD glyphs, so exactness is not claimed for those profiles. Source rich-text fonts are decoded; not every text paragraph has a pixel comparison.

31 simulation tests passed. Browser checks verify character speech and moving mouth frames against actual source cues, all nine Mission01 voices, action fees and item consumption, relations/firing, training cancellation/completion/persistence, original font masks, and existing opening/studio/design/publicity regressions. These signal checks establish live Web Audio output, not physical loudspeaker output. Native Tauri runtime has not been visually exercised.

Further original random quarrel, illness and quitting event-card behavior is not implemented in this action pass. Original files are unchanged, and normal builds require only retained repository assets.
